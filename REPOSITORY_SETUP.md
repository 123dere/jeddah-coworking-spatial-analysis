# Repository setup checklist

Before making the repository public:

1. Replace `YOUR_USERNAME` in `README.md` and `CITATION.cff`.
2. Review every file in `data/processed_public/` for redistribution rights.
3. Do not commit raw Google Maps exports, API keys, geodatabases, journal reviewer correspondence, or private files.
4. Verify basemap/image redistribution rights for each map in `figures/`.
5. Add the final article DOI after publication.
6. Create a GitHub Release such as `v1.0.0`.
7. Optionally connect the repository to Zenodo and archive the release.
8. Add the Zenodo DOI badge and journal citation to the README.

# Reproducibility notes

The original publication workflow used a mixture of ArcGIS Pro / ArcPy and Python.

For portfolio use, this repository:
- removes absolute Windows paths;
- uses command-line arguments and relative paths;
- separates code from data;
- excludes restricted raw data;
- records final statistical result tables.

Exact numerical reproduction requires the same analytical input tables used in the manuscript.

Do not claim full open-data reproducibility if the row-level analytical inputs cannot legally be redistributed. In that case, describe the repository as a reproducible **workflow and code release** with openly shared aggregate results.
